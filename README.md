# Hi, I'm Santiago

Software Engineer and M.Sc. candidate in Systems & Computing Engineering at Universidad de los Andes.

I build software around real decisions: what matters, who needs the system, what can fail, and what should remain under human judgment.

My current work sits at the intersection of **software engineering, developer tooling, cloud systems, and applied AI**.

## What I'm working on

- **Automated program repair** for dependency-update failures in Kotlin Multiplatform.
- **Developer tooling** for understanding the impact of dependency updates across multiplatform projects.
- **LLM systems and evaluation**, including structured evaluation pipelines and human-in-the-loop assessment.
- **Cloud-based AI workflows** using Python, GCP, and Vertex AI.

### Multi-Agent Repair of Dependency Updates in Kotlin Multiplatform

First-author research on a reproducible workflow for repairing failures introduced by dependency updates.

The prototype combines:

- failure reproduction and evidence capture
- failure localization
- evidence-scoped patch generation
- multi-target validation
- auditable explanations

**Stack:** Python · Vertex AI · Kotlin Multiplatform tooling

### KMP-IMPACT

Co-author of a review-support tool for dependency-update pull requests in Kotlin Multiplatform.

The project helps reviewers understand how dependency changes propagate across source sets and platform-specific implementations through static analysis, impact propagation, reviewer-facing visualizations, and optional runtime evidence.

### Colombian Idioms & LLM Evaluation

Led the study end to end, including dataset construction, evaluation-pipeline implementation, model execution, analysis, and paper writing.

The study evaluates **22 LLMs on 8,129 Colombian idiom and regionally marked entries** across recognition, definition generation, and contextual paraphrasing.

Accepted for **oral presentation at LUHME 2026 @ EMNLP 2026**.
